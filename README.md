# Interactive-Sign-Language

## Goals & Deliverables 

The purpose of this project is to work collaboratively and efficiently within a team, adopting a professional project management workflow to plan, design, develop, and evaluate an interactive sign language learning web application platform using computer vision. 

The team aims to achieve a working web application by the prototype submission date on 9th February 2027. The web application should provide visual demonstration of signs and allow users to practise selected signs using camera or video input. If real-time webcam integration proves unfeasible, still-image recognition will be considered as a fallback. The application should recognise signs and provide feedback, support a database of roughly 20 signs, and incorporate gamification or difficulty levels with a user account if time permits. 

## Expected Product

The expected product is a functional web-based prototype that provides structured sign-language learning activities and computer-vision-assisted practice. The platform is expected to include visual demonstrations for a selected set of predefined signs, camera or video input for user practice, hand-landmark detection and analysis, and feedback indicating how closely a user's attempt matches the expected sign. The prototype should also include basic user and progress management, with simple gamification features such as scores, achievements or progress indicators where feasible.
